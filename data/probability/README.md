# Probability artifacts

`target_ledger.parquet`, `oof_ledger.parquet`, `artifact_contract.json` and
`latest_metadata.json` are reproducible local outputs. They are generated by
`matvix train-probabilities` and intentionally excluded from Git because their
digests bind to the local normalized data snapshot and locked runtime.

Run `matvix accept-real` after generation to verify the full probability chain.
